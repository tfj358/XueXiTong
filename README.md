## 目录

- `source/desktop/`：桌面端源码、测试与构建脚本。
- `source/superstar-checker/`：上游 MCP 与本地兼容修复源码。
- `versions/2026-10-28/`：按时间排序的 EXE、报告、日志与发布材料。
- `VERSION_HISTORY.json`：机器可读版本清单。

上传内容排除了虚拟环境、登录会话、个人偏好、学习状态和运行日志。

2.1.1 的最终归档通过 66 项桌面回归测试、23 项上游单元测试、离线安装自检、隔离窗口启动退出检查、Windows 版本属性检查和 SHA256 校验。
