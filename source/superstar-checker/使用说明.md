# Superstar Checker 使用说明

这是一个纯 HTTP 的超星学习通 MCP 工具。开发者版不包含虚拟环境，解压后需要安装依赖。

## 安装

在工程根目录打开 PowerShell：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -e .
```

## 登录

- 双击 `登录超星.bat`：手机号+密码登录
- 双击 `扫码登录.bat`：浏览器显示二维码
- 双击 `扫码登录命令行.bat`：Win32 原生像素窗口显示二维码，不依赖浏览器和终端字体
- 如果当前已有登录会话，三种登录入口都会先显示当前 uid 并询问是否切换账号。直接回车表示取消，不会读取手机号/密码，也不会拉出二维码；确认切换后才会继续。切换会替换旧会话，正在刷课时会先停止。

扫码也可以命令行运行：

```powershell
.venv\Scripts\superstar-checker.exe login --qr --terminal
```

命令行模式默认打开 Win32 原生像素窗口，二维码使用正方形像素并保留白色静区。
若原生窗口不可用，可追加 `--half-block` 使用半块字符，或追加 `--ascii` 使用纯 ASCII 兼容模式。

## 检查

```powershell
.venv\Scripts\python.exe tests\unit_test.py
.venv\Scripts\python.exe tests\smoke_test.py
```
