# 版本记录

## 2.1.1 · 2026-10-28

- 每次构建使用独立暂存与归档目录，已有发布文件保持原样；失败记录独立保存。
- 从 version.txt 生成 Windows 版本资源，发布附源码快照、依赖与验证日志及 SHA256 清单。
- 恢复任务时复查运行状态与课程，清除筛选并选中原课程；只由手动点击启动。
- 停止、失败和异常退出保留恢复入口，正常完成及仅人工/不支持的任务不会循环恢复。
- 统一自动刷新的倒计时和调度，刷新完成后重新计时，繁忙结束后只补一次。
- 故障通知在恢复后重新启用，手动停止单独提示。
- 自动刷新独立异步 HTTP 会话，35 秒总预算包含跳转、请求、退避，最多两次网络重试；退出可取消。
- 增加隔离设置路径、离线安装自检和模拟后端窗口自检，验证不操作真实课程或账号。

## 2.1.0 及更早版本

历史 EXE、说明、检查报告与日志保留在原有位置。原版本记录保持原样，本文件不追填未验证的历史细节。
